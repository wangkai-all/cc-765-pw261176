      录入聚合摘要

      服务端只接收聚合摘要：均值、标准差、有效数量、取值范围。 任何逐记录字段（records / rows / samples / values 等）都会被整体拒绝并返回 422。 一次可提交单个分量，也可用 mean_vector 提交一个单位的整个均值向量。

      或粘贴一批 JSON 摘要（数组）

      注入损坏摘要（演示）

      注入只用于演示：它追加一条新报文并把来源标为“注入”，从不修改或删除原报文。 “更正”会让新报文替换该单位原来的贡献（旧报文保留在库中、不再参与估计）； “拆报”会用新批次再报一次，用来看权重上限能否挡住宿主式的重复计入。

      验证模拟参数

      针对已知真值的虚构面板：单位异质性、独立损坏、协同偏移、虚增数量、超出上限、少量极端值。 收益用“误差 p90”衡量；误伤用“干净面板在改变 α / 上限后的中心漂移”衡量。
