# 理论：截尾汇总的误差界、权重上限与误伤边界

本文说明系统里每个数字的来源，以及它在什么前提下成立。阅读顺序建议：
先看“一句话结论”，再看假设清单，最后看推导和模拟设计。

## 一句话结论

- 截尾汇总以 **α 为崩溃点**：只要损坏摘要的权重份额不超过 α（且单单位权重不超过上限），
  估计中心与“干净总体中心”的偏差不超过一个**可算出**的界。
- 这个界**不是**置信区间，也不假设损坏值随机分布：它对损坏值的任意放置成立。
- 界依赖一条**假设清单**。清单里任何一条不成立，界就被撤销（`void`），而不是放宽后继续使用。
- 模拟只用来**核验**这个界和展示收益，不能替代证明。

## 从摘要到估计

一个单位上报一组**聚合摘要**：均值（或均值向量）、标准差、有效数量、取值范围、批次。
系统不接收任何逐记录字段（见 `server.validate_receipt`），所以：

- 权重使用上报的**有效数量** `n_effective`，这是申报值，不是复核值；
- 各摘要之间无法做内部一致性检验，只能做结构检验（均值必须落在自报范围内，标准差非负等）。

因此“保证”的定语始终是：**在这些申报值本身可信、且污染份额不超过 α 的前提下**。

### 权重上限（水填充）

设单位 `i` 的申报权重为 `w_i`（同一单位跨批次的多条报文先按单位**汇总**）。
要求“任何单位在最终有效权重中的占比不超过 `s`”。直接取
`c = s · Σw_i` 是错的：被截断的单位占比会高于 `s`。正确的上限 `c` 满足

```
c = s · Σ_i min(w_i, c)
```

左边关于 `c` 单调递增、右边关于 `c` 单调不增，故用二分求解（`analysis.resolve_cap`，80 次迭代）。
截断后 `Σ min(w_i, c)` 中每个单位占比恰好 ≤ `s`。

两个边界情况：

1. **不可行**：有正解的条件是「最大申报量本身已 ≤ `s · Σw`（上限根本不需生效）」，
   或者 `k · s ≥ 1`（`k` 为单位数）。两者都不满足时不存在正的 `c`。此时系统**不静默地
   把所有单位压成 0 权重**，而是报告“上限不可行”，并把保证状态置为 `void`。
   判定见 `analysis.cap_feasible`；注意 `k · s ≥ 1` 只是必要条件——若最大单位本就低于份额，
   即便 `k · s < 1` 上限也无需生效。
2. **不约束**：若最大申报权重本身已 ≤ `s · Σw`，上限不生效，`c = max(w)`。

上限不可行时，界面上的边界项显示**用户请求的** `s`（“2%：本面板 29 个单位，任何正上限都
无法把每个单位压到该份额以下”），而不是实际达到的份额，因为后者只有 `1/k` 量级、
与请求值差了一个数量级，写出来会让人误以为请求被部分满足。

### 拆分不能绕过上限

同一单位拆成多条报文（不同批次）时，先按 `unit_id` 汇总申报量，再对一个单位整体应用 `c`，
最后按各报文申报量比例分配这 `c`。因此“拆成 k 份”与“一次报 k 倍”得到的单位权重完全相同，
这一点由 `tests/test_robustagg.py::CapInvariantTests` 直接断言。

### 更正替换而非新增

更正生成一条新报文，其 `revision_of` 指向被替换的报文。有效集合定义为
“没有被任何新报文 `revision_of` 指向的报文”，所以旧报文**自动退出有效集**，
但仍然留在库中（审计、追溯、批次视图均可看到）。更正不会新增一个单位的片段。

## 截尾汇总

按摘要均值排序，从两端各切掉总权重的 `α`（跨界的单位只保留剩余部分的权重）。
写成 `T = Σ_{i∈S} ω_i x_i / Σ_{i∈S} ω_i`，其中 `ω_i` 是截尾后的存活权重。

性质与本文相关的有两条：

1. **崩溃点 = α**：若损坏摘要的总权重 > α，它们可能同时落在同一侧尾部，
   截尾不再能约束其影响。这就是“超过 α 就失去保证”的准确含义。
2. **合法异质性不被判定为坏**：截尾只改变权重，不产生“坏数据”标签；
   离中心远的单位可能只是单位本身不同。系统里唯一的“坏”标签来自
   **生成器的真值**（`known_bad`），仅用于演示打分。

## 误差界

记：

- `s_span`：参与单位取值的极差（最大值 − 最小值）；
- `β`：假定的污染权重份额（取 `β = α`，即按最坏情况申报）；
- `α`：两端截尾比例；
- `c_share`：单单位在最终权重中的实际最大占比（由上面的水填充得到）。

则

```
|T(观测) − 干净总体中心|
    ≤ (β + α + max(0, c_share − α)) · s_span / (1 − 2α)
```

**直觉**：

- `β` 项：损坏质量可以整体移动到一端，最多贡献 `β · s_span`；
- `α` 项：截尾也切掉了干净数据的尾部，这部分干净质量最多偏离中心 `α · s_span`；
- `max(0, c_share − α)` 项：若单个单位权重超过 α，它可能不被完全截掉，
  超出的那部分仍然可以整体偏向一端；
- 分母 `1 − 2α`：截尾后保留的质量，用于把“被切掉的量”换算为均值的偏差。

`bounds.trimmed_bound` 逐项计算并把公式写进 `rationale`，网页上可直接核对。
该界只用到极差，非常保守——这是“对任意放置成立”的代价。

### 假设清单与三档状态

`trimmed_bound` 返回的 `assumptions` 是边界的定义的一部分，不是装饰：

| 条目 | 含义 | 状态来源 |
|---|---|---|
| `alpha_range` | `0 < α < 0.5` | 直接检验 |
| `contamination_ceiling` | 实际损坏权重份额 ≤ α | 演示数据可核验；接收数据**无法核验** |
| `cap` | 单单位上限可达（水填充有解） | 由 `cap_feasible` 判定 |
| `units` | 至少 3 个单位 | 直接检验 |
| `aggregate_only` | 摘要内部一致（无原始记录可复核） | **永远无法核验** |

状态：

- `guaranteed`：全部 `met`。在接收路径上**不会出现**，因为 `aggregate_only` 永远 `unverifiable`。
- `conditional`：有 `unverifiable` 而无 `unmet`。区间**仍然给出**，但明确标注
  “以实际污染 ≤ α 为前提，该前提只能申报”。
- `void`：任一 `unmet`，或 `α ≥ 50%`，或单位不足。此时 `interval = null`，
  网页不画误差带、两处图例都撤掉“误差范围”，并在汇总卡上写明“保证已撤销”。
  既然没有可依赖的界，“两个估计之差是否落在误差范围内”的判定也一并撤回——
  否则会在同一屏上用撤销了的界去为差异背书。

`void` 的触发条件包括“已知损坏份额 > α”（仅演示数据可知），这正是题目要求的
“超出假设时明确失去保证”。

### 这个界不是什么

- 不是 95% 置信区间：没有抽样分布假设；
- 不随样本量收缩到 0：极差和污染份额决定其大小，增加同质单位不会让界消失；
- 不能跨指标复用：每个指标分量独立计算。

## 模拟：收益与误伤

模拟分成两个**不同的问题**，结果分开呈现（`simulation.py`）：

### 1. 收益（`simulate_scenario`）

每个随机种子生成一个**真值已知**的面板，重复 `runs` 次，统计各估计量的
`|估计 − 真值|` 的中位数 / p90 / 最大值，并记录误差界覆盖真值的比例。

生成器的六个场景对应题目要求：

| 场景 | 设计意图 |
|---|---|
| `baseline` | 单位真实异质、无污染：检验稳健估计不误伤合法差异 |
| `independent` | 少数单位独立偏移：检验截尾的基本收益 |
| `coordinate` | 多个单位**协同偏移 + 虚增数量**：检验封顶与截尾一起工作 |
| `inflate_n` | 均值几乎不动、**数量放大**：检验“按 n 加权”被带偏的机制 |
| `over_ceiling` | 污染份额约为 α 的三倍：**必须**撤销保证 |
| `few_bad` | 极少数但极端的坏值 + 大异质性：误伤边界 |

每个面板的 `truth` 由**真实均值 × 真实数量**加权得到（`synthetic.generate`），
损坏单位只改变**申报值**，不改变真值。

在界面默认参数（100 轮，α = 12%，上限 10%，种子 7）下的一次实测结果：

- `independent` / `coordinate` / `inflate_n`：截尾 p90 误差约为直接加权的 1/2 – 1/3；
- 误差界在这些场景中 **100% 覆盖真值**（全部为 `conditional`）；
- `over_ceiling`：**100% 判为 `void`**，覆盖率记为“无评级”，而不是“覆盖失败”；
- `baseline`：截尾与直接加权的差异在同一量级，说明合法异质性没有被系统性削掉。

### 2. 误伤边界（`null_calibration`）

问题：**在完全没有污染的数据上**，改变可信假设（α、上限）会把中心移动多少？

做法：对同一个干净面板，分别用若干组 (α, 上限) 计算各估计量，统计中心漂移的 p90。
这个量衡量“稳健化本身引入的扰动”。设计上要求：

- 截尾/Huber 的漂移应显著小于“改变 α 使直接加权失效”的程度；
- 漂移不应随 α 变化而爆炸——否则说明估计量在干净数据上也不稳定。

网页的“验证模拟”区域把两张表并排呈现：收益看 p90 误差，误伤看漂移。

## 局限（明确写出，而不是隐藏）

1. **申报值不可核验**：`n_effective`、`std`、范围都来自报送方。系统只能拒绝结构非法的报文，
   不能发现“数量虚增但格式合法”。这是一切“条件性保证”的根源。
2. **界的保守性**：只依赖极差，实际误差通常远小于界；不能把界当作精度指标。
3. **α 的语义**：α 同时是截尾比例和假设的污染上限。改 α 会同时改变估计量和保证条件，
   无法只改其一。
4. **分量独立**：均值向量的各分量分别估计，协方差结构未利用。
5. **隔离是决定，不是检测**：系统不会自动把远离中心的单位标为坏数据；
   隔离必须由人填写原因，并记录前后影响，可释放且保留记录。
